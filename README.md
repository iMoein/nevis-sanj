# NevisSanj v2.4.0

Persian/English writing-forensics public app (React + TypeScript), separate private Python training panel, optional ONNX export, and GitHub Pages deployment via Actions.

**Start on macOS:** `bash manage.command` for private training, then `bash start.command` for the public detector. Complete Persian guide: `README_FA.md`.

The public site never uploads user text and never exposes the admin app. Unverified model scores are not shown. Publishing a model requires explicit review. False-positive error on holdout is displayed in the local management panel.

This is NOT a validated general-purpose AI text detector. See `README_FA.md` for limitations, model provenance, Pages activation, and data privacy.
