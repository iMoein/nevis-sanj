# نویس‌سنج ۲.۵.۰

نسخه ۲.۵.۰ طراحی کامل بخش عمومی نسخه ۲.۳ را برمی‌گرداند: تحلیل متن، علامت‌گذاری شواهد، گزارش TXT/JSON، پروفایل آماری، مقایسه سبک و تم روشن/تیره. تنها بخش آموزش از سایت عمومی حذف شده است. **هیچ متن کاربری به پنل آموزش ارسال نمی‌شود.**

## نصب به‌روزرسانی روی مک

فایل ZIP را از حالت فشرده خارج کنید، پوشه `nevis-sanj-v2.5.0` را در Finder باز کنید و فایل `install-update.command` را اجرا کنید. یا:

```bash
cd ~/Downloads/nevis-sanj-v2.5.0
bash install-update.command
```

این نصب فایل‌های خصوصی `admin_data`، محیط `.venv`، مدل‌های منتشرشده `models/published` و `dist/models` و داده‌های تأییدشده را حفظ می‌کند. مسیر پروژه در macOS: `~/Library/Application Support/NevisSanj`. فایل `start.command` سایت و `manage.command` پنل را به صورت دستی نیز اجرا می‌کنند.

سایت: `http://127.0.0.1:4173`  ·  پنل آموزش: `http://127.0.0.1:8765`

## آموزش و کشف خودکار منابع

- پنل خصوصی از **کاتالوگ عمومی Hugging Face** مخزن‌های تازه را کشف و در قسمت «کشف منابع» نمایش می‌دهد. این جست‌وجو یک فهرست ثابتِ URL نیست؛ براساس عبارت‌های موضوعی و آخرین به‌روزرسانی مخازن است.
- یک منبع تازه ابتدا **فقط نامزد بررسی** است و به‌عنوان حقیقت آموزشی پذیرفته نمی‌شود. مدیر باید مجوز، منشأ انسانی/ماشینی و معنی دقیق ستون یا برچسب‌ها را تأیید کند. مجموعه‌های صرفاً ماشینی یا صرفاً انسانی نیز با تأیید صریح قابل ورودند.
- بعد از یک‌بار تأیید منبع، برنامه داده‌های جدید را مرحله‌ای با API Dataset Viewer (حداکثر ۲۰۰ نمونه از هر منبع در هر اجرا) دریافت می‌کند. نمونه‌های تکراری حذف می‌شوند؛ برچسب را مدل پیش‌بینی نمی‌کند.
- نمونه‌ها در `admin_data/discovered` ذخیره می‌شوند و موتور Python فقط **در صورت تغییر داده‌های معتبر** مدل آزمایشی جدید آموزش می‌دهد؛ مدل قدیمی روی سایت باقی می‌ماند تا مدیر نسخه تازه را تأیید کند.
- با فعال‌کردن زمان‌بندی ساعتی در macOS، کشف منابع (حداکثر روزی یک‌بار)، دریافت داده از منابع تأییدشده و بازآموزی، حتی با بسته‌بودن پنل هم اجرا می‌شوند؛ البته مک باید روشن و به اینترنت متصل باشد.
- متن‌های تشخیص‌داده‌شده کاربران عمومی **خودکار به مجموعه آموزشی اضافه نمی‌شوند**. برچسبی که خود مدل حدس زده است نمی‌تواند نقش حقیقت آموزشی داشته باشد.

## محدودیت اعتبارسنجی

این نسخه مسئله گردآوری داده را از نظر فنی حل می‌کند، نه مسئله اثبات دقت. داده بیشتر لزوماً بهتر نیست. مجموعه‌های انتخاب‌شده ممکن است سوگیری موضوعی، برچسب‌های نادرست و محدودیت مجوز داشته باشند. بهتر است آزمون نهایی مستقل از داده‌های آموزشی و به تفکیک زبان، مدل تولیدکننده و سبک متن انجام شود. امتیاز طبقه‌بند احتمال قطعی منشأ متن نیست.

## استقرار GitHub Pages

فقط پوشه `dist` به سایت عمومی منتقل می‌شود. بخش Python، پنل خصوصی، منابع داده و کلیدها نباید منتشر شوند. برای انتشار مدل، ابتدا از پنل نسخه مدنظر را تأیید کنید و سپس `publish.command` را اجرا کنید. این نسخه به اتصال GPTZero یا Sapling احتیاج ندارد. موتور مرورگر TypeScript است و فایل ONNX در صورت ایجاد یک خروجی اختیاری برای توسعه آینده محسوب می‌شود.


## تغییرات نسخه ۲.۵.۱ — ورود ساده‌تر منابع آموزشی
در پنل «کشف منابع» فقط گزینه‌های مرتبط‌تر در ابتدا نمایش داده می‌شوند. مراحل ورود: انتخاب منبع، نمایش نمونه‌ها، تأیید مجوز و منشأ، دریافت و آموزش خودکار مدل آزمایشی. نگاشت متن و برچسب‌های صریح خودکار است؛ برچسب‌های مبهم مانند 0 و 1 را باید دستی بررسی کرد. تنظیمات فنی در بخش پیشرفته مخفی شده‌اند. منابع ردشده و پیش‌بینی مدل به داده آموزشی معتبر تبدیل نمی‌شوند.


## نسخه ۲.۵.۳ — نگاشت منشأ مستند به جای حدس کاربر

منشأ انسانی/AI از ClassLabel، مستندات README و ستون منشأ متن در دیتاست استخراج می‌شود. برای برچسب عددی، کد از روی ۰ و ۱ حدس نمی‌زند. در صورت تناقض یا فقدان مدرک، منبع قابل تأیید نیست. در مسیر تصویری منبع برچسب‌های اصلی به همراه معنی مستند نمایش داده می‌شوند. منابع ناشناخته ویرایش و تأیید خودکار نمی‌شوند.


## نویس‌سنج ۲.۵.۴
پشتیبانی خودکار از مجموعه‌های آموزشی دارای دو ستون مجزای human_text و ai_text اضافه شد. هر ردیف به دو نمونه با برچسب معتبر منشأ و گروه یکسان تبدیل می‌شود؛ هر دو متن باید شرایط کیفیت را پاس کنند و نمونه‌های تکراری کنار گذاشته می‌شوند. هیچ برچسب‌گذاری حدسی یا تأیید خودکار منبع انجام نمی‌شود.


## نسخه ۲.۵.۵ — مسیر مستقل داده‌های فارسی
- جست‌وجوی اینترنتی با عبارت‌های متنوع فارسی، مستقل از انگلیسی انجام می‌شود. فهرست منابع هنگام بازکردن پنل روی فارسی قرار دارد.
- زبان در فهرست اولیه فقط یک سرنخ متادیتایی است؛ هنگام بررسی منبع از خود متن‌ها سنجیده و ثبت می‌شود. منابع با زبان ترکیبی یا نامشخص بدون بررسی بیشتر تأیید نمی‌شوند.
- زمان‌بندی ساعتی برای حداکثر سه منبع تازه فارسی پیش‌نمایش و کنترل کیفیت می‌گیرد؛ هیچ منبعی خودکار تأیید یا منتشر نمی‌شود.
- نمونه‌های انسانی و AI به تفکیک زبان برای مدل فارسی و انگلیسی جمع‌آوری و ارزیابی می‌شوند. تعداد بیشتر داده به‌تنهایی نشانه افزایش دقت نیست.
- مجموعه‌های دارای مجوز NC یا نامشخص در چرخه ورود خودکار مجاز نیستند. دیتاست فارسی بزرگ ehsantorabi در حال حاضر از این مک با HTTP 401 برای خواندن ردیف‌ها مواجه شده و وارد آموزش نشده است.


## نسخه ۲.۵.۶ — داده تک‌دسته‌ای با منشأ مستند
پیکره‌هایی که همه متن‌هایشان ماشینی و با مستندات تولید مدل زبانی، ستون منبع و شناسه مدل تولیدکننده پشتیبانی می‌شوند، بدون حدس انسانی/AI به عنوان منبع تنها-AI شناخته می‌شوند. منبع ibnsina-llm/synthetic-persian-v1 نمونه است؛ شناسایی با الگوی عمومی و مستندات خود دیتاست صورت می‌گیرد، نه لیست شناسه‌های ثابت. تأیید اولیه منبع و انتشار مدل خودکار نیست. متن‌ها فقط به مجموعه زبان اندازه‌گیری‌شده اضافه می‌شوند. این منابع نمونه انسانی تولید نمی‌کنند و با افزودنشان دقت مدل تضمین نمی‌شود.

## نسخه ۲.۵.۷ — کتابخانه برچسب‌خورده منابع GPT و Claude
در پنل خصوصی `http://127.0.0.1:8765/#training`، تب «کتابخانه داده‌های آموزش» اضافه شده است. نمونه‌های ثبت‌شده در SQLite به تفکیک زبان، منبع، خانواده مدل، شناسه مدل و برچسب انسانی/ماشینی شمارش می‌شوند. برای هر منبع کاربرد آموزشی، منشأ ادعایی، مجوز و تعداد نمونه‌های جداشده برای آزمون نمایش داده می‌شود. وجود داده در بانک **به معنی استفاده از همه نمونه‌ها در نسخه منتشرشده روی سایت نیست**.

ابزارهای `tools/import_chatgpt_claude_corpora.py`، `tools/calibrate_fa_cross_source.py` و `tools/evaluate_chatgpt_claude_v3.py` برای **پژوهش محلی و ارزیابی مستقل** هستند؛ داده‌های GPT/Claude و مجموعه‌های آزمون وارد GitHub نمی‌شوند. استفاده از دیتاست با مجوز نامشخص فقط باید پس از بررسی حقوق استفاده انجام شود. خروجی‌های مدل بر اساس اطلاعات منتشرکننده نام‌گذاری می‌شوند و انتساب قطعی نویسندگی محسوب نمی‌شوند. مدل‌های آزمایشی V3 منتشر یا جایگزین موتور فعال مرورگر نمی‌شوند.
