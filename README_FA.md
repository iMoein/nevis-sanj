# نویس‌سنج ۲.۴.۰ — سایت عمومی + پنل آموزش خصوصی

این پروژه در قالب **دو قسمت مستقل** ساخته شده است:

- **سایت عمومی** (React + TypeScript): فقط ورود متن، تحلیل، نتیجه و دریافت گزارش. سازگار با GitHub Pages؛ متن برای تحلیل به سرور ارسال نمی‌شود.
- **پنل آموزش محلی** (Python): ورود مجموعه داده، آموزش طبقه‌بند فارسی/انگلیسی، ارزیابی و تأیید انتشار مدل. فقط روی `127.0.0.1` و فقط روی رایانه شما اجرا می‌شود؛ روی GitHub Pages قرار نمی‌گیرد.

> نتیجه طبقه‌بند، امتیاز خام مدل است و **احتمال قطعی تولید متن توسط AI نیست**. هیچ مدلی بدون نمونه‌های انسانی و ماشینی معتبر منتشر نمی‌شود.

## راه آسان روی مک (۳ مرحله)

### ۱) مدل‌ها را آموزش بدهید

1. ZIP را از حالت فشرده خارج کنید.
2. در پوشه پروژه، `manage.command` را دوبار کلیک کنید یا از Terminal اجرا کنید:

   ```bash
   bash manage.command
   ```

3. پنل خصوصی روی `http://127.0.0.1:8765` باز می‌شود. اگر بسته آموزشی قبلی در `~/Downloads/nevis-sanj-training-pack-v1.1.0/data` باشد، دکمه **واردکردن خودکار از Downloads** کار می‌کند. در غیر این صورت، فایل‌های `training-fa.jsonl` و `training-en.jsonl` را دستی انتخاب کنید.
4. برای هر زبان **آموزش و ارزیابی** را بزنید. اعداد خطای تشخیص متن انسانی و نمونه‌های آزمون را بررسی کنید.
5. برای هر مدل مناسب، دکمه **تأیید و آماده‌سازی برای انتشار** را بزنید. این کار وزن مدل را در `models/published/fa.json` یا `en.json` و در صورت امکان `.onnx` ذخیره می‌کند.

مدل‌های این بسته **به‌صورت پیش‌فرض وجود ندارند**؛ چون داده‌های انسانی کاربر در این گفتگو بارگذاری نشده‌اند. واردکردن و آموزش اولین بار ضروری است. هیچ امتیاز ساختگی نمایش داده نمی‌شود.

### ۲) سایت را پیش‌نمایش کنید

```bash
bash start.command
```

سایت عمومی روی `http://127.0.0.1:4173` اجرا می‌شود. صفحه فقط فلوی بررسی متن دارد. پنل مدیریت از این صفحه قابل دسترسی نیست.

### ۳) انتشار روی GitHub Pages (یک‌بار تنظیم)

مخزن عمومی `https://github.com/iMoein/nevis-sanj` در تاریخ ۳۰ اکتبر ۲۰۲۶ ساخته شده اما هنوز فایل‌های پروژه به آن Push نشده‌اند. از داخل همین پوشه پروژه یک بار این دستور را اجرا کنید:

```bash
bash deploy.command
```

این اسکریپت با حساب `gh` واردشده در مک، مخزن را به `origin` وصل می‌کند، فایل‌ها را Push می‌کند و برای فعال‌شدن GitHub Pages تلاش می‌کند. ممکن است لازم باشد در GitHub بخش **Settings → Pages → Build and deployment → Source = GitHub Actions** را تأیید کنید. آدرس مورد انتظار، *پس از موفقیت انتشار*، `https://imoein.github.io/nevis-sanj/` خواهد بود.

**انتشار مدل در دفعات بعدی:** در پنل خصوصی مدل را تأیید کنید، سپس `bash publish.command` را اجرا کنید. فقط مدل‌های تأییدشده به مخزن ارسال می‌شوند و GitHub Actions سایت را به‌روز می‌کند.

## چه چیزی روی سایت عمومی می‌رود؟

فقط `dist/`، شامل React/TypeScript کامپایل‌شده و مدل‌های **تأییدشده** از `models/published/`.

فایل‌های `admin_data/`، پنل Python، دیتاست‌های خصوصی، مسیرهای مک و متن کاربران **اصلاً در خروجی سایت نیستند**. برای اطمینان، workflow خروجی را از ابتدا برمی‌سازد.

نکته: اگر مدل را در یک مخزن عمومی منتشر کنید، مدل قابل دانلود و استخراج خواهد بود. برای محرمانه‌نگه‌داشتن مدل باید استقرار سمت سرور انتخاب شود.

## آموزش مستمر و GitHub Actions

Workflow جداگانه `Evaluate new candidate models` هفتگی یا دستی اجرا می‌شود. اگر و *فقط اگر* فایل‌های دارای مجوز `training/approved/training-fa.jsonl` و/یا `training/approved/training-en.jsonl` را **آگاهانه** به مخزن اضافه کرده باشید، از آن‌ها مدل آزمایشی می‌سازد و به‌صورت فایل Artifact می‌دهد. هیچ مدل تازه‌ای خودکار منتشر نمی‌شود. داده‌های محرمانه و فاقد مجوز را به مخزن عمومی اضافه نکنید.

مدل Python از هش واژه و چندنویسه + ویژگی‌های ریتم/سبک و رگرسیون لجستیک استفاده می‌کند؛ نمونه‌های موضوعی در دو طرف آموزش/آزمون پخش نمی‌شوند و نمونه‌های بسیار مشابه از آزمون حذف می‌شوند. نمونه‌های کم، نوشته‌های بازنویسی‌شده و ژانرهای ناآشنا ممکن است نتیجه را مخدوش کنند.

## فناوری و محدودیت‌های فعلی

- Python 3.10+، `scikit-learn` و `onnx` برای آموزش و خروجی ONNX.
- React + TypeScript، نسخه استاتیک بدون Backend و بدون API خارجی برای تشخیص.
- مرورگر در استقرار GitHub Pages در صورت وجود ONNX و Runtime Web از WASM استفاده می‌کند؛ در صورت خطای سازگاری یا نبود آن، همان مدل خطی را مستقیماً با TypeScript اجرا می‌کند. بسته Runtime فقط در GitHub Actions به سایت اضافه می‌شود؛ اجرای محلی بدون آن نیز کار می‌کند.
- React همراه سورس از بسته نسخه قبلی حفظ شده و قبل از عرضه عمومی گسترده باید همراه زنجیره build به نسخه پشتیبانی‌شده ارتقا پیدا کند.
- GitHub Actions برای اجرای هفتگی در مخزن عمومی بدون فعالیت ممکن است پس از ۶۰ روز غیرفعال شود؛ برای شروع مجدد از تب Actions استفاده کنید.

**مهم:** با مجموعه ۵۶ نمونه فارسی/۶۴ نمونه انگلیسی که در اختیار دارید می‌توان مسیر فنی را آزمایش کرد، اما دقت تجاری روی متن‌های جدید ثابت نمی‌شود. نتایج باید روی مجموعه مستقل بزرگ‌تر تکرار شوند.
