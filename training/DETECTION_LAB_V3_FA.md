# آزمایشگاه تشخیص نویس‌سنج V3 — وضعیت اجرایی
این قابلیت فقط در پنل محلی `http://127.0.0.1:8765/#lab` فعال است. از مدل منتشرشده سایت عمومی مستقل است.

## بخش‌های اجراشده
- ارزیابی فارسی/انگلیسی با TF-IDF کم‌حافظه و مقایسه Logistic Regression و Linear SVM.
- تقسیم گروه‌محور، کالیبراسیون امتیاز با گروه‌های جداگانه، انتخاب آستانه فقط روی Validation.
- ثبت Confusion Matrix و Recall/FPR/AUC؛ در آزمون ثابت طول متن، حوزه، Brier و بازه اطمینان Wilson ۹۵٪ گزارش می‌شود.
- محافظت از ورود دوباره نمونه‌های آزمون ثابت به SQLite/آموزش و ثبت هم‌پوشانی دقیق.
- برگرداندن بخش قابل‌بازیابی اطلاعات منشأ به SQLite؛ موارد باقی‌مانده با منشأ ناقص مشخص می‌شوند.
- آزمون مستقل بین‌منبعی انگلیسی؛ مجموعه یادگیری و آزمون مجزا هستند، اما ممیزی کامل منابع بالادستی انجام نشده است.
- صف Active Learning برای بازبینی خطاهای بانک داده، بدون برچسب‌گذاری خودکار و بدون دست‌کاری مدل.
- محاسبه آزمایشی قابل‌حمل JS برای مدل V3 و بررسی نزدیکی خروجی Python/JS؛ این ماژول هنوز به UI عمومی متصل نیست.
- دروازه انتشار برای V3 به‌طور پیش‌فرض بسته است و به آزمون مستقل چندمدلی/چندمنبعی، عملکرد قابل قبول و سازگاری کامل مرورگر نیاز دارد.
- پنل با درخواست مجدد و گزارش خطای قابل‌فهم در برابر قطع موقت API مقاوم شده است.

## نتایج اولیه (به معنای دقت تضمین‌شده نیست)
- آزمون مستقل فارسی: ۲۰۰ متن انسانی، FPR=۱٪؛ هیچ متن AI در این مجموعه نیست.
- انگلیسی با نامزد کالیبره‌شده ۸٬۰۰۰نمونه‌ای: روی ۶۰۰ نمونه مجزا Recall AI=۵۶٪ و FPR انسانی=۵٪.
- آزمایش بین‌منبعی انگلیسی روی ۹۰۰ نمونه: Recall AI=۸۴٫۹٪ و FPR انسانی=۲۳٫۶٪. این اختلاف مانع انتشار است.
- روی آزمون کامل کنارگذاشته‌شده انگلیسی ۲٬۰۰۰تایی هم Recall و FPR جداگانه گزارش می‌شوند؛ موضوعات نامتوازن‌اند.
- آزمونهای Python و JavaScript، Build و تست صفحه پنل باید پیش از هر نسخه جدید تکرار شوند.

## باقی‌مانده برای صلاحیت انتشار
- مجموعه داده مستقل و هم‌موضوع با GPT/Claude/Gemini و نویسندگان انسانی دارای منشأ قابل بررسی؛ داده‌های بازنویسی و ترکیبی نیز جدا شوند.
- آزمونهای Cross-model، Matched-topic، Paraphrase، Hybrid هنوز با داده کافی قابل اجرا نیستند، بنابراین پنل صریحاً `needs_data` نشان می‌دهد.
- مجموعه آزمون مستقل خارجی نباید برای انتخاب مدل، آستانه یا تنظیم ابرپارامتر استفاده شود.
- آزمایش Transformer باید با وزن مجاز، منابع سخت‌افزاری و آزمون مستقل انجام شود؛ در این پیاده‌سازی دانلود/آموزش آن به‌صورت مصنوعی شبیه‌سازی نمی‌شود.
- نمونه بازبینی‌شده فقط پس از بررسی واقعی سند منشأ و تأیید مجدد اجازه ورود به دیتاست آموزشی جدید دارد. صرف پیش‌بینی مدل مدرک نیست.
- قبل از انتشار نیاز به سازگاری کامل استقرار Schema 3، تست بین مرورگری، پروفایل کارایی و پذیرش دستی است.
